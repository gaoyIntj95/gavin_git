# 智碳咨询模块使用指南

## 功能概述

智碳咨询模块已升级为 **"RAG 知识库 + 轻量智能体" 双模式**，支持：

### 1. RAG 知识库问答模式

- 基于上传的专业文档进行智能问答
- 支持 PDF/Word/Excel/TXT 文档解析和向量化
- 自动检索相关文档片段作为上下文
- 使用本地 Ollama 大模型生成回答
- 内置降级规则：Ollama 不可用时使用规则匹配

### 2. 智能体问答模式

- 除了知识库，还能调用业务工具查询项目数据
- 可用工具：
  - `get_project_info`: 获取项目基本信息（名称、行业、标准、边界等）
  - `get_emission_summary`: 获取项目排放数据（总排放、Scope1/2占比、重点排放源等）
- 自动判断是否需要调用工具
- 支持关联特定项目进行业务查询

### 3. 会话管理

- 多会话支持，每个会话独立的历史记录
- 会话列表管理（新建、切换、删除）
- 会话可关联特定项目和问答模式
- 自动保存对话历史

### 4. 快捷问题

- 预置高频问题，一键提问
- 分类标签（核算标准、基础概念、CBAM、碳市场等）
- 支持从后端动态加载

### 5. 知识库管理

- 文档上传（支持 PDF/Word/Excel/TXT/Markdown/CSV）
- 文档列表管理（查看、删除）
- 自动分块和向量化存储
- 文档状态跟踪（处理中/已完成/失败）

## 安装和配置

### 1. 安装 Python 依赖

```bash
cd D:\Carbon_AI_Project
pip install -r requirements.txt
```

新增依赖：

- `langchain==0.3.23`
- `langchain-community==0.3.21`
- `langchain-ollama==0.3.2`
- `chromadb==0.6.3`
- `pypdf==5.4.0`
- `ollama==0.4.8`

### 2. 安装和启动 Ollama

#### Windows:

```bash
# 下载并安装 Ollama
# 访问 https://ollama.com/download

# 启动 Ollama 服务
ollama serve

# 拉取推荐模型（在另一个终端）
ollama pull qwen2.5:7b
ollama pull nomic-embed-text
```

### 3. 配置环境变量

创建 `.env` 文件或设置系统环境变量：

```bash
# Ollama 服务地址（默认：http://127.0.0.1:11434）
OLLAMA_BASE_URL=http://127.0.0.1:11434

# 对话模型（默认：qwen2.5:7b）
OLLAMA_CHAT_MODEL=qwen2.5:7b

# 嵌入模型（默认：nomic-embed-text）
OLLAMA_EMBEDDING_MODEL=nomic-embed-text

# 是否启用降级规则（默认：true）
RAG_FALLBACK_ENABLED=true
```

可选模型（按性能排序）：

- `qwen2.5:7b` - 推荐，7B参数，中文效果好
- `qwen2.5:14b` - 更强，需要更多内存
- `llama3:8b` - Llama 3，英文强
- `mistral:7b` - Mistral，平衡性能

### 4. 初始化数据库

数据库会在首次启动时自动初始化，包括：

- 创建新表（knowledge_documents, quick_questions, chat_sessions）
- 为 chat_history 表添加新列（mode, project_id）
- 预置 10 条快捷问题

### 5. 启动后端

```bash
cd D:\Carbon_AI_Project\carbon_ai
uvicorn app.main:app --host 127.0.0.1 --port 8017 --reload
```

### 6. 启动前端

```bash
cd D:\Carbon_AI_Project_frontend_vue
npm install
npm run dev
```

## 使用方法

### 基础 RAG 问答

1. 上传知识文档（如 ISO 14064-1 标准 PDF）
2. 选择 "知识库问答" 模式
3. 输入问题，例如："ISO 14064 和 JS/T 303 的区别是什么？"
4. 系统会检索相关文档并生成回答

### 智能体问答

1. 选择 "智能体问答" 模式
2. 可选择关联项目（如项目 ID = 1）
3. 输入问题，例如："我的项目排放数据是多少？"
4. 智能体会自动调用工具查询项目数据并回答

### 会话管理

- **新建会话**: 输入新的会话ID
- **切换会话**: 从下拉列表选择现有会话
- **删除会话**: 点击"删除当前会话"按钮

### 快捷问题

1. 点击快捷问题卡片直接提问
2. 分类标签：核算标准、基础概念、CBAM、碳市场、排放因子、数据质量、绿电、业务查询

### 知识库管理

1. 点击"上传文档"按钮
2. 选择文件（支持 PDF/Word/Excel/TXT/Markdown/CSV）
3. 等待处理完成（自动分块和向量化）
4. 可查看文档列表或删除不需要的文档

## 降级机制

当 Ollama 服务不可用时，系统会自动降级为规则匹配模式：

| 关键词    | 回答内容                                     |
| --------- | -------------------------------------------- |
| 组织边界  | 解释三种方法：运营控制法、控股法、财务控制法 |
| Scope 1   | 直接排放定义和分类（固定燃烧、移动燃烧等）   |
| Scope 2   | 间接排放定义（外购电力、热力）               |
| Scope 3   | 其他间接排放（上下游排放）                   |
| ISO 14064 | ISO 14064-1:2018 标准说明                    |
| JS/T 303  | 公共机构核算标准说明                         |
| CBAM      | 碳边境调节机制说明                           |
| 履约      | 碳市场履约流程和优化策略                     |
| 排放因子  | 因子来源优先级和选择方法                     |
| 不确定性  | 评估方法和计算公式                           |

## API 请求示例

### RAG 问答

```bash
curl -X POST http://127.0.0.1:8017/api/chat/ask \
  -H "Content-Type: application/json" \
  -d '{
    "session_id": "demo-session",
    "question": "Scope 1 的定义是什么？",
    "mode": "rag"
  }'
```

```bash
curl -X POST http://127.0.0.1:8017/api/chat/ask \
  -H "Content-Type: application/json" \
  -d '{
    "session_id": "demo-session",
    "question": "我的项目排放数据是多少？",
    "mode": "agent",
    "project_id": 1
```

```bash
curl -X POST http://127.0.0.1:8017/api/chat/knowledge/upload \
  -F "file=@ISO_14064-1_2018.pdf"
```

```bash
curl http://127.0.0.1:8017/api/chat/sessions
```

```bash
curl http://127.0.0.1:8017/api/chat/quick-questions
```

## 故障排查

### Ollama 连接失败

```bash
# 检查 Ollama 服务是否运行
curl http://127.0.0.1:11434/api/tags

# 如果失败，重启 Ollama 服务
ollama serve
```

### 向量化失败

```bash
# 检查嵌入模型是否下载
ollama list

# 如果没有，拉取嵌入模型
ollama pull nomic-embed-text
```

### 文档上传失败

- 检查文件大小（建议 < 50MB）
- 检查文件格式是否支持
- 查看后端日志获取详细错误

### 问答超时

- 调整前端超时时间（`useApi.ts` 中的 timeout）
- 切换到更小的模型（如 `qwen2.5:7b`）

## 性能优化建议

1. **向量检索优化**：
   - 增加检索文档数（修改 `k` 参数）
   - 调整分块大小（修改 `CHUNK_SIZE`）

2. **模型选择**：
   - 生产环境推荐：`qwen2.5:14b`
   - 开发/测试：`qwen2.5:7b`
   - 资源受限：`mistral:7b`

3. **缓存策略**：
   - 相同问题的回答可考虑缓存
   - 向量检索结果可缓存短时间

4. **并发控制**：
   - 文档上传队列化处理
   - 限制并发问答请求数量
