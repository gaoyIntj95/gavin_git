# 项目代码思维导图（后端理解版）

> 目标：先看懂 `D:\Carbon_AI_Project\carbon_ai` 这套后端初稿的结构和主链路，再做改造。

---

## 1. 先建立全局认知（你要先知道“这是谁在做什么”）

后端技术栈是 **FastAPI + SQLAlchemy + Pydantic + SQLite**。  
代码分层是标准的：

- `app/main.py`：应用入口（创建 FastAPI、挂载路由、启动初始化）
- `app/api/*`：接口层（HTTP 入参出参、调用 service）
- `app/services/*`：业务层（核算、报告、履约、CBAM、问答逻辑）
- `app/models/*`：数据模型（数据库表）
- `app/schemas/*`：接口契约（请求/响应校验）
- `app/core/*`：配置和数据库基础设施
- `app/utils/*`：工具函数（比如 Excel/CSV 解析）

## 3. 关键文件职责速查

### 基础设施
- `app/core/config.py`：配置中心（目录、数据库 URL、报告目录等）
- `app/core/database.py`：SQLAlchemy engine/session、建表、因子种子数据

### 核心 API
- `app/api/projects.py`：项目 CRUD
- `app/api/emission_sources.py`：排放源 CRUD、批量导入、核算、校验
- `app/api/reports.py`：三类报告生成+下载
- `app/api/carbon_market.py`：配额缺口+履约优化
- `app/api/cbam.py`：CBAM 提取+模板导出
- `app/api/chat.py`：提问+会话读取

### 核心 Service
- `app/services/calculation_service.py`：核算汇总与校验规则
- `app/services/factor_service.py`：因子匹配（按类别/行业/地区/有效期）
- `app/services/report_service.py`：报告内容拼装与文件输出（txt/docx）
- `app/services/carbon_market_service.py`：配额与成本优化规则
- `app/services/cbam_service.py`：CBAM 指标估算与 CSV 模板输出
- `app/services/rag_service.py`：规则问答

## 4. 当前“最该先关注”的联调点

你后续改代码时，优先检查前后端接口是否一致（这是现在最容易出问题的地方）：

1. 聊天历史路径：
   - 前端常写成 `/api/chat/history/{session_id}`
   - 后端当前是 `/api/chat/sessions/{session_id}`

2. 履约分析路径：
   - 前端常写成 `/api/compliance/analyze`
   - 后端当前是 `/api/carbon-market/quota-gap/{project_id}` + `/optimize/{project_id}`

3. CBAM 税费路径：
   - 前端常写成 `/api/cbam/tax`
   - 后端当前没有该路由，只有 `/extract/{project_id}` 与 `/template/{project_id}`
