# 登录权限系统使用指南

## 系统概述

已为智碳管家项目添加完整的登录权限系统，包含以下功能：

- ✅ JWT Token 身份认证
- ✅ 用户登录/退出
- ✅ 角色权限控制（admin/user）
- ✅ API 端点权限拦截
- ✅ 前端登录页面
- ✅ 自动 token 注入请求头

## API 端点

### 1. 登录

```http
POST /api/auth/login
Content-Type: application/json

{
  "username": "admin",
  "password": "admin123"
}
```

**响应：**

```json
{
  "access_token": "eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9...",
  "token_type": "bearer"
}
```

以下端点需要登录才能访问：

| 端点                                        | 权限要求 | 说明         |
| ------------------------------------------- | -------- | ------------ |

## 前端使用

### 1. 登录页面

访问 `http://localhost:5173`，会自动显示登录页面。

**登录流程：**

1. 输入用户名和密码
2. 点击"登录"按钮
3. 登录成功后自动跳转到首页
4. Token 保存在 `localStorage` 中（key: `access_token`）

**快捷填入演示账号：**

- 点击"管理员"按钮 → 自动填入 `admin / admin123`
- 点击"普通用户"按钮 → 自动填入 `demo / demo123`

---

### 2. Token 自动注入

所有 API 请求会自动携带 `Authorization: Bearer <token>` 请求头，无需手动添加。

**实现位置：** `src/composables/useApi.ts`

```typescript
function buildFetchOptions(method: string, body: unknown): RequestInit {
  const options: RequestInit = { method };

  const token = localStorage.getItem("access_token");
  if (token) {
    options.headers = { Authorization: `Bearer ${token}` };
  }
  // ...
}
```

---

### 3. 退出登录

点击左侧边栏底部的"退出登录"按钮，会清除 token 并返回登录页面。

## 前端权限控制

在组件中可以获取当前用户信息：

```vue
<script setup lang="ts">
import { getCurrentInstance } from "vue";

const instance = getCurrentInstance();
const currentUser = instance?.exposed?.currentUser;

// 判断是否为管理员
const isAdmin = currentUser.value.role === "admin";
</script>

<template>
  <button v-if="isAdmin">管理员专属操作</button>
</template>
```

## 安全建议

1. **更换 SECRET_KEY**

   ```python
   # 生成随机密钥
   import secrets
   SECRET_KEY = secrets.token_urlsafe(32)
   ```

2. **启用 HTTPS**

   ```python
   # 使用 uvicorn 启动时
   uvicorn app.main:app --host 0.0.0.0 --port 443 --ssl-keyfile key.pem --ssl-certfile cert.pem
   ```

3. **缩短 Token 有效期**

   ```python
   ACCESS_TOKEN_EXPIRE_MINUTES = 60 * 8  # 8小时
   ```

## 故障排查

### 1. 登录后立即返回登录页

**原因：** Token 无效或过期

**解决：**

- 检查 `SECRET_KEY` 是否与生成 token 时一致
- 检查 token 是否过期
- 清除浏览器 `localStorage` 重新登录

---

### 2. API 返回 401 Unauthorized

**原因：** 未携带 token 或 token 无效

**解决：**

- 检查是否已登录
- 打开浏览器控制台，查看 Network 请求头是否有 `Authorization`
- 检查 token 格式是否正确：`Bearer <token>`

---

### 3. 管理员权限检查失败

**原因：** 用户角色不是 `admin`

**解决：**

- 检查数据库中用户的 `role` 字段
- 直接修改数据库：
  ```sql
  UPDATE users SET role = 'admin' WHERE username = 'your_username';
  ```
