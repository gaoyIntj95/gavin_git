# 修复登录超时问题

## 问题原因

依赖未安装，导致后端无法正常处理登录请求。

## 解决方案

在 **Anaconda Prompt** 中执行以下命令：

```bash
cd D:\Carbon_AI_Project\carbon_ai
conda activate py311
pip install python-jose[cryptography]==3.3.0 passlib[bcrypt]==1.7.4
```

## 验证依赖

```bash
# 验证依赖是否安装成功
python -c "import jose, passlib; print('Auth dependencies OK')"

# 启动后端
uvicorn app.main:app --host 127.0.0.1 --port 8017 --reload
```

## 测试登录

后端启动后，访问 `http://localhost:5173`，使用以下账号登录：

| 用户名 | 密码     |
| ------ | -------- |
| admin  | admin123 |
| demo   | demo123  |

---

## 已修复的前端超时问题

登录请求超时时间已从 8 秒增加到 **30 秒**。

**修改位置：** `src/composables/useApi.ts:76`

```typescript
const isAuthLogin = path === "/api/auth/login";
const timeout = isUpload
  ? 60000
  : isChatAsk
    ? 120000
    : isAuthLogin
      ? 30000
      : 15000;
```

## 如果仍有问题

1. **检查后端是否启动**
   - 打开浏览器访问 `http://127.0.0.1:8017/docs`
   - 应该看到 FastAPI 文档页面

2. **检查数据库**
   - `D:\Carbon_AI_Project\carbon_ai\carbon_ai.db` 文件是否存在
   - 如果不存在，删除后重新启动后端（会自动创建）

3. **查看后端日志**
   - 启动后端的终端应该没有错误信息
   - 如果有错误，记录具体信息

4. **清除浏览器缓存**
   - 按 `F12` 打开开发者工具
   - 在 Application 标签中清除 Local Storage
